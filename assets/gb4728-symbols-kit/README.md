## 2. 标准依据

| 分部 | 现行版本 | 本图集覆盖 |
|---|---|---|
| 第 2 部分 符号要素、限定符号和其他常用符号 | GB/T 4728.2-2018 | 接地 |
| 第 3 部分 导体和连接件 | GB/T 4728.3-2018 | 端子 / 端口（Vcc、Vee、In、Out 的记号来源） |
| 第 4 部分 基本无源元件 | GB/T 4728.4-2018 | 电阻器、电容器、电位器 |
| 第 5 部分 半导体管和电子管 | GB/T 4728.5-2018 | 二极管、LED、NPN、PNP、N-JFET、N-MOS |
| 第 6 部分 电能的发生与转换 | GB/T 4728.6-2022 | 电压源 |
| 第 13 部分 模拟元件 | GB/T 4728.13-2022 | 运算放大器 |

GB/T 4728 等同采用 IEC 60617，所以图框右上标注 `idt IEC 60617`。

**要分清"强制图形"和"行业约定"**：

- **强制**：电阻是矩形（不是锯齿线）、增强型 MOS 沟道为三段断线、NPN/PNP 靠发射极箭头方向区分、粗线只用于基极横条与沟道等。
- **约定**：Vcc/Vee 的横杠画法、In/Out 的五边形旗标、电源端引线长度。国标只规定端子的一般画法，这些属于工程习惯。画在图上时要说明，别当成标准原文。

## 3. 坐标系统：1 单位 = 1 毫米

```xml
<svg width="297mm" height="210mm" viewBox="0 0 297 210">
```

- `viewBox` 与页面毫米数一一对应，于是**任何坐标值就是毫米数**。
- 线宽写 `stroke-width="0.45"` 就是 0.45 mm，打印 1:1 时实测即 0.45 mm。
- 好处：所有数字可心算、可对照标准尺寸表；坏处：Inkscape 的 `--export-area` 用 px，必须乘 3.7795（见第 9 节）。

---

## 4. 栅格：2.5 mm 模数（最容易做错的地方）

### 4.1 三条硬约束

1. 栅格 pattern 的原点固定在 `(0,0)`：

   ```xml
   <pattern id="grid" width="2.5" height="2.5" patternUnits="userSpaceOnUse">
   ```

   `userSpaceOnUse` + 不写 `patternTransform` ⇒ 格线落在 `0, 2.5, 5, …`，即 **2.5 的整数倍**。

2. **每个引脚端点**必须满足 `x / 2.5 ∈ ℤ` 且 `y / 2.5 ∈ ℤ`。
3. **每个符号组的 `translate()` 原点**也必须是 2.5 的整数倍（因为引脚坐标是相对原点写的）。

满足 2 + 3，引脚才必然落在格线交点上。

### 4.2 由此推出的取值习惯

- 引脚常用 `±12.5`（2 端元件跨距 25 mm = 10 格）、`±5`、`(2.5, -12.5)` 这类值。
- **本体轮廓不必在格点上**：矩形 12×4、圆半径 8.4、三角 5×8 都可以是任意值——只有"引脚端点"和"组原点"受约束。
- 图框、标题栏、行/列位置也统一取 2.5 的倍数，让格线与图框严格重合。

### 4.3 反面教材

早期版本给符号组加了 `scale(1.15)` 放大，引脚就落在 `12.5 × 1.15 = 14.375` 处，与栅格差了 1.875 mm——**缩放会以乘法破坏加法建立的栅格关系**。要么 1:1 画，要么就别承诺"对齐格点"。

## 5. 线宽、线帽、箭头

| 元素 | 线宽 | 说明 |
|---|---|---|
| 细线（引线、轮廓、极板、二极管三角） | 0.45 | 默认继承自图层 |
| 粗线（BJT 基极横条、JFET 沟道、MOS 沟道三段、电源横杠） | 0.9 | 加 `stroke-linecap="butt"` |

**线帽必须区分**：

- 一般线用 `round`，端点圆润、接头处自然。
- **粗线用 `butt`**。否则 0.9 mm 的圆头会在端点鼓出半径 0.45 mm 的圆包，JFET 沟道两端会变成"哑铃"。
- 粗线与细线相接时，细线起点放在粗线**内部**（如 x=0 而不是 x=±0.45），可避免圆头露出。

**箭头一律是填充三角形路径**，不用 `<marker>`：

```
<path d="M 1.3 6.8 L -0.786 5.774 L 0.274 4.714 Z" fill="#0f172a" stroke="none"/>
```

`marker` 会随 `stroke-width` 缩放、在缩放组里更难控制；直接算三个点最稳。算法：给定箭尖 B、方向单位向量 u、长 L、半宽 W，另两点为 `B - L·u ± W·p`，p 是 u 的法向量。

## 6. 版面参数（A4 横向 297×210）

| 项目 | 取值 |
|---|---|
| 外框 | `(10, 10)` 275×187.5，0.7 mm |
| 内框 | `(12.5, 12.5)` 270×182.5，0.25 mm |
| 标题分隔线 | y=40，x 16→282.5；16→58 段加粗到 1.1 |
| 标题栏 | `(175, 170)` 107.5×25，分栏线 y=177.5 / 185 |
| 行（符号原点 y） | 60 / 102.5 / 145（行距 42.5） |
| 列（第 1 行 6 个） | 35, 80, 125, 170, 215, 260（间距 45） |
| 列（第 2、3 行 5 个） | 42.5, 95, 147.5, 200, 252.5（间距 52.5） |
| 序号基线 | 46 / 88.5 / 131 |
| 名称基线 | 78 / 120.5 / 163 |
| 标准号基线 | 82 / 124.5 / 167 |

**行距为什么是 42.5**：一个 25 mm 高的符号 + 序号 4 mm + 名称 8 mm + 标准号 4 mm ≈ 41，留 1.5 余量。三行合计 127.5 mm，正好塞进 40→168 的可用高度。

**中英文四行的代价**：加一行英文名需要约 5 mm/行，三行就超 15 mm，A4 放不下。所以本版只保留"序号 / 中文名 / 标准号"。要双语得换 A3 或拆两页。

## 7. SVG 文件结构

### 7.1 五个图层

```xml
<g inkscape:groupmode="layer" inkscape:label="栅格"     id="layer-grid">
<g inkscape:groupmode="layer" inkscape:label="图框"     id="layer-frame">
<g inkscape:groupmode="layer" inkscape:label="图面文字" id="layer-text">
<g inkscape:groupmode="layer" inkscape:label="图形符号" id="layer-symbols">
<g inkscape:groupmode="layer" inkscape:label="符号标注" id="layer-labels">
```

顺序即叠放顺序：栅格在最底，标注在最上。白底的标题栏要放在"图框"层，才能盖住格线。

### 7.2 样式继承（拆分素材时的关键）

```xml
<g id="layer-symbols" fill="none" stroke="#0f172a" stroke-width="0.45"
   stroke-linecap="round" stroke-linejoin="round">
  <g inkscape:label="01 电阻器" transform="translate(35,60)">
    <rect …/>                      ← 自己不写 fill/stroke，继承自图层
  </g>
```

**子组不重复声明样式**让主文件干净，但**一旦把子组抠出来单独存盘，`fill` 会退回默认的黑色、`stroke` 会退回 `none`**，结果就是一块实心黑矩形。拆素材时必须显式补上这五个属性（`make-symbols.py` 里是从 `layer-symbols` 读出来再写回去的）。

### 7.3 符号组的约定

- `inkscape:label="01 电阻器"`：给人看，同时 `make-symbols.py` 用 `^(\d\d)\s` 匹配编号。
- `transform="translate(cx,cy)"`：只平移，绝不缩放。
- 组内坐标以**符号中心**为原点，引脚坐标写死在 `±12.5` 之类的位置。

## 8. 制作流程

```
① 手写 SVG      → ② Inkscape 渲染 → ③ 目检（行条带/引脚放大）
        ↑                                      ↓
        └──────── ④ 修正几何 ←─────────────────┘
⑤ 出图（PNG/PDF） → ⑥ 拆素材（16×2） → ⑦ 校验（栅格/透明）→ 打包
```

这个循环跑了 6 轮才定型。**别指望一次画对**，尤其是指南针式的方向细节（发射极箭头朝向、LED 箭头方向、电位器滑动端位置）。

## 9. Inkscape 命令速查

```bash
INK="/c/Program Files/Inkscape/bin/inkscape.exe"
```

| 目的 | 命令 |
|---|---|
| 整页 PNG | `"$INK" sheet.svg --export-type=png --export-filename=out.png --export-dpi=300` |
| A4 PDF | `"$INK" sheet.svg --export-type=pdf --export-filename=out.pdf` |
| 局部裁切 | `"$INK" sheet.svg --export-type=png --export-area=x0:y0:x1:y1 --export-dpi=1200` |
| 透明底 | 追加 `--export-background-opacity=0` |
| 查询对象包围盒 | `"$INK" sheet.svg --query-all`（输出 `id,x,y,w,h`，单位 px） |

**单位陷阱**：`--export-area` 和 `--query-all` 都用 **px**（96 dpi），而我们的坐标是 mm。换算：

```bash
area() { awk -v a="$1" -v b="$2" -v c="$3" -v d="$4" \
  'BEGIN{printf "%.2f:%.2f:%.2f:%.2f", a*3.7795275591, b*3.7795275591, c*3.7795275591, d*3.7795275591}'; }
```

（1 mm = 96 / 25.4 = 3.7795275591 px）

## 10. 校验

### 10.1 引脚对格 `check-grid.py`

解析 SVG，把每个符号组的局部坐标换算成绝对坐标，检查 bbox 四条边是否落在 2.5 的整数倍上：

```
symbol                    xmin    xmax    ymin    ymax   bbox edges on grid (x-,x+,y-,y+)
01 电阻器                  22.5    47.5    58.0    62.0   YYnn
07 NPN                    30.0    50.9    90.0   115.0   YnYY
```

`n` 只允许出现在**本体轮廓方向**（电阻的上下边、二极管三角、三极管圆、Vcc 横杠两端）。**引脚方向必须是 `Y`**，出现 `n` 说明有引脚跑偏了。

### 10.2 透明底 `check-alpha.py`

```python
corners = [im.getpixel(p)[3] for p in ((0,0),(w-1,0),(0,h-1),(w-1,h-1))]
alpha.getextrema()   # 期望 (0, 255)
```

判据：四角 alpha 必须为 0（真透明），且整图最大 alpha 为 255（确实有实心笔画）。只看"PNG 有 alpha 通道"不够——可能整张图是白的。

### 10.3 目视

- `out/row1|row2|row3.png`：600 dpi 行条带，查间距、查文字碰撞。
- `out/grid-pin-h|v.png`：1200 dpi 单引脚放大，确认线端压在格线交点上。

## 11. 踩坑清单

| # | 现象 | 原因 | 解法 |
|---|---|---|---|
| 1 | Inkscape 报 XML 解析错误，整页不出图 | 注释里写了 `<!-- ---------- 01 ---------- -->`，XML 注释禁止出现 `--` | 分隔符改用 `[01]`、`·`、`====` |
| 2 | 局部裁切位置完全错 | `--export-area` 用 px，我按 mm 传了 | 乘 3.7795，封装成 `area()` |
| 3 | 引脚差 1.875 mm 对不上格 | 符号组带 `scale(1.15)` | 去掉缩放，按 1:1 重定义几何 |
| 4 | 拆出的素材变成实心黑块 | `fill="none"` / `stroke` 继承自父图层，拆出后丢失 | 拆分时补写 `fill/stroke/stroke-width/linecap/linejoin` |
| 5 | 独立 SVG 里全是 `ns0:` 前缀 | `ET.tostring(子树)` 会重映射命名空间 | `ET.register_namespace("", svg_ns)` 后从根节点序列化 |
| 6 | 素材里出现多余空行/缩进错乱 | 深拷贝带走了原文件的空白文本节点 | 可忽略（不影响渲染），或在序列化前清理 |
| 7 | 粗线端点鼓成圆包 | 图层默认 `stroke-linecap="round"` | 粗线单独加 `stroke-linecap="butt"` |
| 8 | 素材边缘把文字裁掉 | 估算文字宽度偏小 | 按 0.62 em/字、基线上方 0.78 em 保守估；宁大勿小 |
| 9 | PowerShell 调用 Git Bash 参数被吞 | PowerShell 会剥掉内层引号，`grep "a b"` 变成两个参数 | 复杂命令写进 `.sh` 文件再执行 |
| 10 | 控制台中文乱码 | Windows 控制台 GBK 与 UTF-8 不符 | 只影响日志，文件本身是 UTF-8 |
| 11 | PNG 有白底 | 未显式关掉背景 | `--export-background-opacity=0` 并用 alpha 校验 |
| 12 | 序号被引线穿过 | 序号 y 固定，而个别符号（运放 V+ 引线）更高 | 序号跟着该行最高符号的顶部走，或整行下移 |

### 画法本身的错误（比工具坑更值得记）

- **电位器箭头画到了电阻体下方**：滑动端应指向电阻体上边中点。
- **LED 箭头方向反了**：应朝外（斜上），表示发光。
- **集电极/发射极上下颠倒**：NPN 的 C 在上、E 在下，箭头背离基极。
- **MOS 沟道与栅极粘在一起**：增强型必须"栅极独立 + 沟道三段断线"。
- **二极管阴极管画粗**：国标用等宽细线，粗线只留给半导体符号的基极/沟道。

## 13. 素材拆分算法（`make-symbols.py`）

对每个符号组：

1. **算包围盒**：几何元素取精确值；文字按保守估算（宽 `0.62·font-size·字数`，基线上方 `0.78·fs`、下方 `0.22·fs`）。
2. **向外取整到栅格**，再留边：
   ```
   xs = floor((xmin − 2.5) / 2.5) · 2.5
   xe = ceil ((xmax + 2.5) / 2.5) · 2.5
   ```
   于是边距 ≥ 2.5 mm，且画布边界本身落在 2.5 的整数倍上。
3. **平移量 `dx = cx − xs`、`dy = cy − ys` 同样是 2.5 的整数倍** ⇒ 引脚在新画布中仍在格点上。脚本里对每个引脚做断言：
   ```python
   assert abs(px / 2.5 - round(px / 2.5)) < 1e-6
   ```
4. 新 SVG 的 `width/height` 用 mm，`viewBox` 与画布同尺寸；文件头注释写上名称、标准号、画布尺寸、全部引脚坐标——拿着注释就能在别的软件里精确定位。
5. PNG 用 `--export-dpi=1200 --export-background-opacity=0` 导出，再用 `check-alpha.py` 验透明。

结果：每个符号的画布都不同（10×30 到 35×35），但**引脚相对画布的坐标永远是 2.5 的倍数**，可以精确拼接。

```bash
# 4) 渲染透明 PNG + 校验通道（用 Bash 循环调用 Inkscape）
bash build/make-symbols.sh      # 或手工：for f in symbols/*.svg; do "$INK" ...; done

# 5) 校验引脚是否落在格点
python build/check-grid.py

# 6) 打包
python build/make-zip.py
```

> `check-alpha.py` 需要 Pillow。系统 Python 没装时，用任意带 Pillow 的解释器跑即可（例如 DSH 运行时的 Python）。

## 15. 扩展指引

**加一个新符号（比如电池）**

1. 在 `layer-symbols` 里加 `<g inkscape:label="17 电池" transform="translate(cx,cy)">`，`cx/cy` 取 2.5 的倍数；
2. 引脚端点取 2.5 的倍数；
3. 在 `layer-labels` 补序号/名称/标准号三行；
4. 在 `build/make-symbols.py` 的 `META`、`PINS` 各加一条；
5. 跑 `make-symbols.py build` → 断言会替你把关。

**换 A3 双语版**：页面 `420×297`，行距可放到 60，恢复英文行；`check-grid.py` 不用改。

**做 Inkscape 符号库**：把 16 个 `<g>` 抽成 `<symbol id="resistor">`，用 `<use>` 引用；素材文件改成引用同一份 defs。

**去标注版素材**：删掉各符号组里 `<g stroke="none" fill="#64748b">` 的管脚字母（C/B/E、D/G/S、V+/V−、1/2/3），重新生成即可。

## 16. 一句话总结

> **1 单位 = 1 mm + 2.5 mm 模数 + 引脚坐标永远是 2.5 的整数倍 + 1:1 不许缩放**，这四条守住，符号就永远能对齐、能拼、能复用；剩下的都是几何审美问题。
