## 2. 技术质量评估

| 维度 | 结论 | 依据 |
|---|---|---|
| **坐标系** | ✅ 极佳 | `viewBox="0 0 W H"` 与毫米一一对应，**1 单位 = 1 mm**；线宽 `0.45` 就是 0.45 mm |
| **栅格** | ✅ 极佳 | 2.5 mm 模数；**每个引脚端点**都是 2.5 的整数倍（已逐个核对） |
| **线宽规范** | ✅ 好 | 细线 0.45、粗线 0.9；粗线强制 `stroke-linecap="butt"`，避免端点"哑铃" |
| **图层** | ✅ 好 | 5 图层顺序清晰；样式集中在 `layer-symbols` 上继承 |
| **元数据** | ⚠️ 半成品 | 每个 SVG 顶部有注释：名称 / 标准号 / 画布 / **引脚坐标**；但**没有引脚名** |
| **引脚坐标可得性** | ✅ | `make-symbols.py` 的 `PINS` 表 + SVG 注释双重来源，两者一致 |
| **位图** | ✅ | 1200 dpi、透明底、有 alpha 校验脚本 |
| **脚本可移植性** | ⚠️ | Inkscape 路径写死 `C:\Program Files\Inkscape\bin\inkscape.exe`；Python 3.13 |
| **工程量** | ✅ 小 | 单个 SVG 0.5~1.5 KB，全库 16 KB 级；渲染开销可忽略 |

## 3. 一个容易忽略的好设计：SVG 顶部注释是机器可读的

```xml
<!-- NPN 型晶体管 / NPN Transistor | GB/T 4728.5 | 画布 27.5 x 35 mm (2.5 mm 栅格) | 引脚: (2.5,17.5) (17.5,5) (17.5,30) -->
```

一行注释同时给出**名称、标准号、画布尺寸、引脚坐标**。这意味着 `symbols.json`
可以由脚本**从素材衍生**，而不是手抄一份一定会漂移的表。

⚠️ 但注意：注释里的坐标是**画布绝对坐标**，而 `make-symbols.py` 的 `PINS` 是**符号中心为原点的局部坐标**。
两者差一个 `translate`：

```
07-npn: <g transform="translate(15.0,17.5)">，画布 (2.5,17.5) − (15,17.5) = (−12.5, 0) = 基极 ✓
```

生成 manifest 时必须**统一到一套坐标系**（建议：局部坐标 + 记录 `translate`）。

## 5. 缺口：画一块**真实踏板**还缺什么

按"日常效果器"的实际需要排优先级：

| 优先 | 缺的符号 | 为什么需要 | 备注 |
|---|---|---|---|
| ~~P0~~ | ~~电解电容（极性）~~ | — | **暂不考虑**（决策 D-006：器件库没有极性模型，极性不影响仿真） |
| ~~P0 开关~~ | ~~SPST / SPDT~~ | — | **不需要**：D-007 本项目不做开关，图纸不出现开关符号 |
| **P1** | **插孔**（输入/输出/DC 座） | 图纸完整性、接线说明 | 国标里属连接件 |
| ~~P1 脚踏开关~~ | — | — | **不需要**（同上，D-007） |
| **P1** | **旋钮/电位器带开关**（如音量带电源开关） | 部分老式踏板 | 可选 |
| **P2** | 齐纳 / 肖特基的**限定符号** | 电源保护、削波 | 基础符号 + 限定符号即可 |
| **P2** | 电感 | 部分 wah / 滤波 | |
| **P2** | 光耦 / LDR | 光电压缩类 | |
| **P2** | 测试点 / 未连接（NC）/ 跳线 | 图纸可读性 | |
| **P3** | 变压器 / BBD / 数字门 | 特殊电路 | 非第一优先级 |

> 注：**旋转/镜像不需要额外素材** —— 由编辑器对同一份 SVG 做变换即可
> （这也是原始素材坚持"只 translate 不 scale"的好处）。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **引脚名缺失** | 生成网表时要按名字绑定引脚（`C/B/E`、`a/k`、`IN+/IN-/V+/V-/OUT`），只有坐标是不够的 | `docs/04` 定义 `symbols.json`，把"编号 + 名称 + 局部坐标 + **SPICE 引脚序**"写死；由脚本生成 + 漂移检查 |
| **注释坐标与 `PINS` 表可能漂移** | 两处数据不一致时生成的引脚位置会错 | 生成脚本**同时读两者并交叉校验**，不一致就报错 |
| **符号种类不够** | 画不了完整踏板（开关/插孔） | `docs/06` 的 D1 阶段补 P0 符号；在补齐前允许"符号占位 + 手写网表片段" |
| **脚本是 Windows 路径** | macOS 上跑不了导出流程 | 只用于**离线生成资产**；设计器运行时不依赖 Inkscape（前端直接渲染 SVG）。需要重导出时把 `INK` 改成环境变量 |
| **许可**（见 §7） | 发布时的法律风险 | 保留署名与来源；商业发布前确认 |
| **A4 图集不可用于编辑** | 那是"符号对照表"，不是画布 | 编辑器画布自建（A3/A2、2.5 mm 栅格、可缩放），只复用 `symbols/*.svg` |

## 7. 许可与署名（已确认）

- **全部 16 个符号均为按 GB/T 4728（等同采用 IEC 60617）手绘的 SVG 源码**，版权归本项目所有（决策 D-001）；
- 随本仓库以 **GPL-3.0-or-later** 分发；
- 采用"与任何 CAD 软件相同"的使用方式：以这些图形符号绘制技术图纸，不复制标准文本；
- 图纸与「关于」页保留署名：`符号依据 GB/T 4728（idt IEC 60617）`。

> 补画的符号沿用同一套规范与同一份署名（放在 `assets/gb4728-ext/`，**不修改原 kit**）。

## 8. 结论

| 判断 | 结论 |
|---|---|
| 能否直接支撑 PoC？ | ✅ 能。rustomp 器件闭集 100% 有符号 |
| 能否直接支撑"画完整踏板"？ | ⬜ 需补 P0（电解电容、开关、脚踏开关），P1（插孔、DC 座） |
| 是否需要改造素材？ | 不需要改 SVG；**需要新增一份 `symbols.json`**（引脚名 + SPICE 引脚序） |
| 最大隐患 | 引脚名的结构化数据缺失（可脚本解决），其次是许可确认 |
