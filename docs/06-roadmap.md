# 分阶段计划

> 原则：**每一步都以"能画出 Sparklin Drive 并生成可仿真的网表"为牵引**，
> 不铺开做过早的抽象。

---

## D0：骨架（预计最小）

| 项 | 内容 | 验收 |
|---|---|---|
| 工程 | `frontend/`（Vite + TS，零运行时依赖）+ `backend/`（axum） | ✅ `npm run dev` + `cargo run` 能通 |
| 协议 | JSON-RPC：`designer.ping` / `designer.symbols` / **`designer.netlist`** | ✅ 前端拿得到符号清单与网表 |
| 符号清单 | `tools/gen-symbols.py` → `symbols/symbols.json`（16 符号 + 引脚名），与 kit 的 PINS 表交叉校验 | ✅ `--check` 无漂移 |
| 画布 | SVG 画布 + 2.5 mm 栅格 + 中键平移/滚轮缩放 | ✅ |
| 模态编辑 | `r/c/w/q/m/空格/d` + `esc`、`ctrl+r`/`ctrl+e`、撤销重做 | ✅ |
| 网表导出 | 并查集求网络、正交导线、`in=/out=` 指令、单份 `.cir` + lint（6 条） | ✅ 9 个后端测试（含黄金文件） |
| 预览截图 | 工具栏「预览」→ 可保存 PNG（D-008） | ✅ |

> D0 的关键不是界面，而是**符号清单**：它错了，后面所有坐标都是错的。

## D1：能画图、能出网表

| 项 | 内容 |
|---|---|
| 元件 | 放置/拖动/旋转/镜像/删除；参考编号自动分配；属性面板（值 + 型号下拉） |
| 导线 | 折点绘制、T 型连接、junction 圆点、删除时级联 |
| 连通性 | 并查集求网络；自动命名 `n1…`（按坐标排序）；接地 → `0` |
| 端口 | `node-in`/`node-out` 符号 + 网络名 → `in=`/`out=` 指令 |
| 网表 | `designer.netlist` 输出 `.cir`（§`docs/05`），**确定性字节** |
| Lint | 悬空引脚 / 重复编号 / 无地 / 型号闭集（error 阻断导出） |
| 验证 | 画一张 Sparklin Drive 的简化版（运放 + 2 二极管 + 3 电阻 + 2 电容），导出的 `.cir` 能被 ngspice 跑出合理波形 |
| ~~开关符号 / 分支导出~~ | **取消**（D-007）：本项目不做开关，开关是插件层的子电路切换，不进网表 |
| **预览 = 截图** | 工具栏「预览」→ 弹窗显示画布位图，可保存 PNG（D-008） |

> D1 结束的标志：**设计器画出来的图，`rustomp-import --mna` 能直接生成可编译的 `Ckt`。**

## D2：画完整踏板

| 项 | 内容 |
|---|---|
| 符号 P1 | 插孔（in/out）、DC 座、旋钮、测试点、NC |
| 电位器接法 | 分压 / 可变电阻两种接法，属性面板选择；自动生成 `P1A/P1B` + `param` |
| 图纸 | 标题栏、图框、注释文字、参考编号/数值的显示开关 |
| 导出 | SVG（打印）、PNG（截图/预览） |
| 模板 | 内置几个常用模板：非反相放大、共射前级、二极管削波、电源滤波 |

---

## D3：边画边验证

| 项 | 内容 |
|---|---|
| 仿真 | 复用 breadspice 的 `designer.simulate`（链接 `rustomp-oracle`）：`op` / `ac` / `tran` |
| 波形 | 示波器面板（复用 breadspice 的 FFT/对数轴实现） |
| 一键生成 | 画 → 网表 → `mna_codegen` → 显示生成的 Rust，并给出**对拍结果**（THD 对比） |
| 差异提示 | 设计器算出的 THD 与 rustomp 基线不一致时高亮（说明某处接法不同） |
| 分支对拍 | 每个分支各自跑一次"设计器仿真 vs 生成的 `Ckt`"，逐分支报告 |

> D3 是"设计器的价值放大器"：**画完就知道声音对不对**，
> 而不是等到插件编译进宿主才发现。

## 里程碑对照

| 里程碑 | 定义 | 与 rustomp 的关系 |
|---|---|---|
| **M-A** | 画出的图 → `.cir` → ngspice 能跑 | 只依赖 ngspice |
| **M-B** | 画出的图 → `.cir` → `rustomp-import --mna` 生成 `Ckt` 并通过编译 | 依赖 rustomp S1a/S1b（✅ 已完成） |
| **M-C** | 生成的 `Ckt` 的 THD 与设计器自己的仿真一致（同一把尺子） | 依赖 `rustomp-oracle` |
| **M-D** | 生成的 `Ckt` 直接进插件（`Engine<Ckt>`）并在 Logic 里出声 | 依赖 rustomp 插件链路（✅ 已有） |

## 明确不做

| 不做 | 原因 |
|---|---|
| PCB 布局 / 布线 | 这是原理图设计器，不是 EDA 全家桶 |
| 3D 预览 / 面板外壳 | 面板由 GUI 设计器负责（另一个项目） |
| SPICE 仿真引擎 | 用 ngspice（经 `rustomp-oracle`） |
| 器件模型编辑 | 型号是闭集；要加型号去 rustomp 的 `devices/` 标定 |
| 自动布局 / 自动布线 | 手画原理图本来就该人来控制 |
| **开关元件（任何形式）** | 决策 D-007："开关不进网表"铁律 —— 开关是插件层的子电路切换，本项目连符号都不提供 |
| **分支 / 变体导出** | 同上：设计器只导出**单份** `.cir` |
| 电解电容符号 | 决策 D-006：器件库无极性模型，暂不考虑 |
