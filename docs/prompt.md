# 我对该项目的一些想法

这个项目是rustomp所用的电路设计器，在正式开始之前，我要尽可能告诉你一些需求。

## 架构

本项目的架构可高度复用breadspice，以减少重复工作量。

## 界面

界面布局大致为：上方一排操作类按钮，包含撤销、重做、仿真、预览、生成网表、文件导入导出等。中间为画布，画布为坐标格子。与breadspice不同的是，由于本项目定位专业设计，因此主界面不提供拖放式元件库。下方为状态栏，点击按钮可展开查看网表。

## 操作逻辑

本项目主要交互逻辑为多模式编辑，不提供自由拖放，使用者需按快捷键进入特定模式后，进行元件放置与编辑。

### 模式
esc 退出到查看模式。查看模式下可双击元器件编辑属性。
r 放置电阻，鼠标光标变成电阻，左键单击画布放置。放置成功后继续放置下一个，除非esc退出。
c 放置电容，具体逻辑同r。
w 画导线，鼠标光标变成画笔，点击后设置第一个锚点，之后可往上、下、左、右四个方向虚化延伸，再次点击设置第二个锚点，从而确定一条直线段，如此重复，直至esc退出。
q 删除模式，按下q后鼠标光标变成剪刀，点击任何元件即可删除，若点击导线则只删除该直线段，按esc退出。
m 移动模式，按下m后，鼠标光标变成手爪，再点击任何元件即可将其拿起，而不影响周围与其连接的其他元素，再次点击画布区域放下，按esc退出。如在手中有元件时按esc，则恢复到拿起前状态。
空格 元件库，弹出窗口显示所有可用的元件符号。点击某元件即进入放置模式，逻辑同r。
d 复制模式，按d后，鼠标光标变成粘贴板符号，点击画布上某元件，即进入该类元件放置模式，放置后生成一个新的同类元件，除id外属性，与原先元件相同。复制一次后，鼠标又回到初始粘贴板符号，可继续复制其他元件，除非按esc退出。

### 补充操作
ctrl+r 在任意放置模式或移动模式下，按该组合键，将手里的元件顺时针旋转90度。
ctrl+e 在任意放置模式或移动模式下，按该组合键，将手里的元件左右镜像翻转。

## 元件

元件的引脚标注（如E、B、C等）应与SVG图形解耦，方便元件旋转时字符保持正确方向。
元件周围应有浮动的位号，在元件属性里可设置别名，默认不显示别名。
查看模式下，双击元件后打开属性编辑器，此部分可高度复用breadspice实现。
为了提升与ngspice的兼容性，INPUT元件内部封装breadspice式的正弦波发生器，OUTPUT元件内封装breadspice式的示波器。此设计仅针对ngspice仿真，不进入最终插件电路。
