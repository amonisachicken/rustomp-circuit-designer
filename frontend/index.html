快捷键

      

        
键作用

        
esc回到查看模式（手持元件时先放回原位）

        
r放置电阻（连续放置，esc 退出）

        
c放置电容

        
g放置接地点

        
空格元件库（全部 18 个符号）

        
w画导线（只走上下左右；直段自动接续）

        
q删除（点元件删元件；点导线删该段）

        
m移动（点元件拿起，点画布放下，esc 放回）

        
d复制（点元件 → 进入同类放置）

        
ctrl/⌘+r顺时针旋转 90°（放置或手持时）

        
ctrl/⌘+e左右镜像（放置或手持时）

        
⌘/ctrl+z撤销

        
⌘/ctrl+y重做

        
中键拖拽 / 滚轮平移 / 缩放视图

        
双击元件属性面板（参考编号 / 别名 / 型号 / 数值 + 单位 / 旋转）

        
h这个帮助

        数值输入：左边填数字、右边选单位（电阻默认 kΩ、电容默认 nF、电压源单位固定 V）。
